paper-explainer

paper-explainer は、arXiv に公開された研究論文の解説動画を作成し、ユーザーが許可した YouTube チャンネルへアップロードするための個人用ツールです。

主な機能

  • 論文の解説動画の制作支援
  • OAuth 認証を通じた YouTube 動画のアップロード
  • 許可されたチャンネル情報・動画情報の参照（該当する機能を利用する場合）

Google アカウントとの連携

Google OAuth を使用し、ユーザーが明示的に許可した権限の範囲内で YouTube Data API を利用します。
