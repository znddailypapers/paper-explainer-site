プライバシーポリシー

本ポリシーは、個人用ツール「paper-explainer」における Google ユーザーデータの取り扱いを説明するものです。

取得・利用する情報

本アプリは、ユーザーが許可した範囲で YouTube Data API を使用し、動画のアップロードに必要な認可情報を利用します。YouTube 読み取り権限を許可した場合は、許可されたチャンネルおよび動画の情報を参照することがあります。

利用目的

論文解説動画の YouTube へのアップロード、およびユーザーが指示した YouTube 関連操作の実行に限定します。

情報の保存と保護

OAuth 認証トークンを保存する場合は、認証の再実行に必要な範囲に限り、アプリの実行環境に保存します。トークンは一般公開用の GitHub リポジトリや GitHub Pages に掲載しません。

第三者への提供

本アプリは、Google ユーザーデータを広告目的で販売しません。ユーザーが要求した YouTube API 操作およびサービスの実行に必要な通信を除き、第三者に提供しません。

アクセス権の取り消し・データの削除

ユーザーは Google アカウントの接続管理 から本アプリのアクセス権を取り消せます。実行環境に保存したトークンやアプリ関連データは、利用者自身が削除できます。

変更について

アプリの機能やデータの取り扱いが変わった場合、本ポリシーを更新します。
